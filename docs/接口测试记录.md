# 接口测试记录

> 测试环境：Windows 11 / Python 3.10.9 / 项目 `.venv`
> 启动命令：`.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`
> 数据库：`data/app.db`（SQLite，WAL 模式）
> 测试时间：2026-10-27 16:34

## 一、用例汇总

| 用例 | 请求 | 预期结果 | 实际结果 | 结论 |
|------|------|----------|----------|------|
| 健康检查 | `GET /health` | 200；status=ok | 200；`{"status":"ok","message":"AI QA Platform is running"}` | 通过 |
| 模型列表 | `GET /api/models` | 200；含 mock 和至少一个真实模型 | 200；返回 mock、deepseek-chat | 通过 |
| mock 问答 | `POST /api/chat`，user_id=1，model_name=mock | 200；返回 answer、session_id | 200；session_id=1，latency_ms=58 | 通过 |
| 真实模型问答 | `POST /api/chat`，model_name=deepseek-chat | 200；answer 非空 | 502；`MODEL_CALL_FAILED`（未配置 MODEL_API_KEY） | 待配置 Key 后复测 |
| 历史查询 | `GET /api/history/1` | 200；按时间倒序 | 200；total=2，id 2 在前、id 1 在后 | 通过 |
| 越权查询 | `GET /api/history/2`，`X-User-Id: 1` | 403/404；不泄露他人数据 | 403；`FORBIDDEN` | 通过 |
| 软删除 | `DELETE /api/history/1` | 200；is_deleted=1 | 200；`{"deleted":true,"session_id":1}` | 通过 |
| 重复删除（幂等） | 再次 `DELETE /api/history/1` | 200；结果一致 | 200；同样返回 `deleted=true` | 通过 |
| 删除后查询 | `GET /api/history/1` | total 减少，已删记录不返回 | 200；total=1 | 通过 |
| 空问题 | `POST /api/chat`，question="" | 422；提示问题不能为空 | 422；`VALIDATION_ERROR`，detail 含 string_too_short | 通过 |
| 非法模型 | `POST /api/chat`，model_name=unknown | 404；提示可用模型 | 404；`MODEL_NOT_FOUND`，detail 含可用列表 | 通过 |
| 不存在用户 | `POST /api/chat`，user_id=999 | 404 | 404；`NOT_FOUND` 用户 999 不存在 | 通过 |
| 删除不存在会话 | `DELETE /api/history/99999` | 404 | 404；`NOT_FOUND` 会话 99999 不存在 | 通过 |

## 二、用例明细

### 1. 健康检查

```
GET /health
```

响应 200：

```json
{"status": "ok", "message": "AI QA Platform is running"}
```

### 2. 模型列表

```
GET /api/models
```

响应 200：

```json
{"models": [{"model_name": "mock", "display_name": "Mock 模型"}, {"model_name": "deepseek-chat", "display_name": "deepseek-chat"}]}
```

### 3. mock 问答

```
POST /api/chat
{"user_id": 1, "question": "你好", "model_name": "mock"}
```

响应 200：

```json
{"session_id": 1, "answer": "这是 mock 模型的回答：你好（当前为本地联调模式，未调用真实大模型）", "model_name": "mock", "latency_ms": 58, "status": "success"}
```

### 4. 真实模型问答（待复测）

```
POST /api/chat
{"user_id": 1, "question": "真实模型", "model_name": "deepseek-chat"}
```

响应 502：

```json
{"success": false, "code": "MODEL_CALL_FAILED", "message": "模型 API Key 未配置，请先在 .env 中设置 MODEL_API_KEY", "detail": null, "request_id": "req_49b4a1b978fa"}
```

说明：`.env` 中 `MODEL_API_KEY` 为空，链路已按预期走到真实模型分支并返回 502；
填入有效 Key 后重新执行本用例即可确认 200。

### 5. 历史查询

```
GET /api/history/1?limit=20&offset=0
```

响应 200（两条记录，session_id=2 在前）：

```json
{"user_id": 1, "total": 2, "items": [
  {"session_id": 2, "question": "再问一次", "answer": "这是 mock 模型的回答：再问一次（...）", "model_name": "mock", "created_at": "2026-10-27 16:34:01"},
  {"session_id": 1, "question": "你好", "answer": "这是 mock 模型的回答：你好（...）", "model_name": "mock", "created_at": "2026-10-27 16:34:01"}
]}
```

### 6. 越权查询

```
GET /api/history/2
X-User-Id: 1
```

响应 403：

```json
{"success": false, "code": "FORBIDDEN", "message": "无权访问其他用户的数据", "detail": null, "request_id": "req_7f24780b7750"}
```

### 7. 软删除与幂等

```
DELETE /api/history/1
```

第一次 200：`{"deleted": true, "session_id": 1}`
第二次 200：`{"deleted": true, "session_id": 1}`

### 8. 空问题

```
POST /api/chat
{"user_id": 1, "question": "", "model_name": "mock"}
```

响应 422：

```json
{"success": false, "code": "VALIDATION_ERROR", "message": "请求参数校验失败",
 "detail": [{"type": "string_too_short", "loc": ["body", "question"], "msg": "String should have at least 1 character"}],
 "request_id": "req_8c858099e8e6"}
```

### 9. 非法模型

```
POST /api/chat
{"user_id": 1, "question": "hi", "model_name": "unknown"}
```

响应 404：

```json
{"success": false, "code": "MODEL_NOT_FOUND", "message": "模型 unknown 不存在",
 "detail": {"available_models": ["mock", "deepseek-chat"]}, "request_id": "req_5c519197b60f"}
```

## 三、查库结果

### 表清单

```
sqlite> select name from sqlite_master where type='table' and name not like 'sqlite_%';
api_call_logs
chat_sessions
users
```

### users

| id | username |
|----|----------|
| 1 | demo_user_1 |
| 2 | demo_user_2 |

### chat_sessions

| id | user_id | model_name | question | is_deleted | deleted_at |
|----|---------|------------|----------|-----------|------------|
| 1 | 1 | mock | 你好 | 1 | 2026-10-27 16:34:01 |
| 2 | 1 | mock | 再问一次 | 0 | NULL |

### api_call_logs

| id | user_id | session_id | model_name | status | latency_ms | error_message |
|----|---------|-----------|------------|--------|-----------|---------------|
| 1 | 1 | 1 | mock | success | 58 | NULL |
| 2 | 1 | 2 | mock | success | 32 | NULL |
| 3 | 1 | NULL | deepseek-chat | error | 0 | 模型 API Key 未配置，请先在 .env 中设置 MODEL_API_KEY |

结论：

- 每次问答都写入 `chat_sessions`，`user_id` 能区分用户
- 每次模型调用都写 `api_call_logs`，失败时 `session_id` 为空且 `error_message` 非空
- 软删除只改标记，不物理删除，历史查询自动过滤
